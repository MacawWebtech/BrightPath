1. Project Overview

BrightPath Academy is a production-grade, zero-truncation, multi-role commercial website template crafted for academic tutoring institutes, K-12 coaching centers, standardized exam test-prep hubs, and private educational academies.

The design synthesizes supportive academic mentorship with structured, grade-wise course discovery matrices.

19 Public Pages

2 distinct Homepages, Subject Catalog, Tutor Directory, Batch Timetable, Blog with detail page, Fee Calculator, and Full Authentication Suite.

Parent Dashboard

Dedicated portal for parents tracking student attendance %, test reports, weekly timetables, online fee invoices, and printable payment receipts.

Admin Dashboard

Comprehensive administrative back-office managing students, faculty load, batch capacities, free demo approvals, and fee collections.

3. Strict Architectural Rules & Design System

3.1 Three-Color Rule

The entire template rigorously restricts its palette to only three core colors. No secondary greens, oranges, or purples are introduced. All state changes, hover effects, and tints are derived via opacity and tone scales of these three hues:

1. Pure Black
#0B0F19

Primary dark ink, dark-mode body surface, headings.

2. Crisp White
#FFFFFF

Primary light surface, dark-mode typography, clean cards.

3. Academic Cobalt Blue
#1D4ED8

Primary CTA buttons, active tabs, grade badges, brand focus.

3.2 Two-Font Rule

  • Headings: Plus Jakarta Sans (Weights: 600, 700, 800) applied to h1–h6, hero headlines, and stat values.
  • Body & UI: Inter (Weights: 400, 500, 600) applied to paragraphs, buttons, navigation, data tables, and input fields.

3.3 30px Global Padding & 8px Spacing Scale

Across desktop (≥1024px) and tablet (640–1023px) viewports, all content maintains padding-left: 30px; padding-right: 30px; (variable --padding-x: 30px). On mobile viewports (<640px), padding smoothly adjusts to 16px with zero horizontal overflow.

3.4 Equal-Height Cards Architecture

Every card row is governed by CSS Grid and Flexbox: grid-auto-rows: 1fr combined with .card { display: flex; flex-direction: column; } and .card-footer { margin-top: auto; } ensures cards in the same row share identical heights and horizontal CTA alignments.

5. Parent Portal Dashboard (8 Pages)

A supportive, intuitive monitoring console located in parent-dashboard/ where parents oversee their child's academic progress.

  • Student Switcher: Switch between siblings in one click (e.g., Alex Miller — Grade 10 and Chloe Miller — Grade 6) with automatic context updates.
  • Real-Time Attendance: Subject-wise percentage bars and an interactive "Report Absence" modal form.
  • Scorecards & Progress: Filterable mock test result logs, performance charts, and printable Official Report Card modals.
  • Fee Payment Receipts: Pending invoice checkout with dummy gateway integration and downloadable, printable payment receipts.

7. The 7-Step Interactive Booking Wizard

Implemented in assets/js/booking.js and embedded within pages/batch-timings.html:

  1. Step 1: Select Grade Level & Core Subject
  2. Step 2: Choose Batch Timing or Free Demo Option
  3. Step 3: Select Preferred Subject Tutor
  4. Step 4: Pick Available Date & Interactive Time Slot
  5. Step 5: Enter Student & Parent Details (validated live)
  6. Step 6: Review Consolidated Summary
  7. Step 7: Confirm Booking → Generates unique Reference ID (e.g., STK-XXXX) and navigates to booking-confirmation.html

8. Dark Mode & RTL Engine

Toggle controls are available on every page header, mobile drawer, and dashboard topbar:

// Dark Mode: Toggle data-theme attribute on root <html> document.documentElement.setAttribute('data-theme', 'dark'); // or 'light' localStorage.setItem('brightpath-theme', 'dark'); // RTL Engine: Toggle dir and lang attributes document.documentElement.setAttribute('dir', 'rtl'); document.documentElement.setAttribute('lang', 'ar'); localStorage.setItem('brightpath-rtl', 'true');

9. Customization Guide

Changing the Primary Brand Color

To rebrand BrightPath Academy, open assets/css/style.css and update the :root custom properties:

:root { --color-primary: #1D4ED8; /* Replace with your institute's primary color */ --color-primary-hover: #1E40AF; /* Lighter/Darker shade of primary */ --color-black: #0B0F19; /* Neutral dark base */ --color-white: #FFFFFF; /* Neutral light base */ }

10. Deployment & Commercial Standards

BrightPath Academy is 100% static, requires zero build tools or compilers, and is compatible with GitHub Pages, Cloudflare Pages, Netlify, Vercel, Apache, or Nginx servers. Simply upload the project root to your web host.
